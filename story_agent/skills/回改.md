# 回改：改了前面的章节之后核对后文

用在：作者要改一个已定稿的章节，或改一条已成立的设定、事实。

## 步骤

1. **先改前章。** 按作者的要求用 edit 改，经审批。
2. **列出改变了什么事实。** 对照 故事状态.md，写出这次改动让哪些"已成立的事实""人物知道什么""未回收的线索"变了。写在对话里，让作者看见。
3. **逐章对照后文。** 从改动的下一章起，每一章 read 一遍，用 search 找提到这些事实的句子，列出受影响处：文件、原文引用、为什么受影响、建议怎么改。一章一章来，不跳。
4. **逐处提议改法。** 每章的改动一张审批卡。作者不批准就按意见调整。
5. **全部核对完再更新 故事状态.md。** 中途不更新，避免状态和正文对不上。
6. 最后 review 改过的每一章。

## 不做

- 不因为一处小改就重写整章。只动受影响的句子。
- 不默认后文没受影响。没检查过的章节明确告诉作者"还没核对"。
