# 审读：审一章正文的清单

这份清单给 review 工具用，也给你自己复读用。清单只管「查什么」；
提醒的字段、引用长度、输出格式由 review 工具自己规定，这里不重复。

## 必查

1. **冲突**：与 故事状态.md、设定/、人物/ 或前文正文矛盾的地方。时间、地点、物件在谁手里、谁在场，逐项核。
2. **认知越界**：人物说了、想了、做了只有在他知道某事时才会有的反应，而 故事状态.md 说他不知道。
3. **新设定**：正文引入了设定/ 里没有的持久事物、规则、机构、能力。行业"铁律"、职务、器物、地名、新人物都算，哪怕只是叙述里顺口带出的。逐条列出来，交作者决定是留是删。
4. **偏差**：与 大纲.md 里本章剧情或结尾状态不符。尤其是结尾状态：正文结束时的事实和大纲写的是否一致。
5. **读者体验**：读者会在哪里卡住。信息给早了、给晚了、一段里塞了太多新东西、动作顺序说不通、对话没有推进。
6. **温度**：哪一段只有摄像机、没有人。引那一段，说清缺的是身体反应、心声，还是一个他在乎的人。
   心声也有浅的：念头句句完整、条理分明，没有闯进来的杂念、没有岔开和改口；
   或者读着像一篇谈自己感受的文章。还有"他感到""他意识到"把读者隔在外面。
7. **做作**：哪里为了有感觉而用力过猛，或者一眼看得出是套出来的。常见的样子：
   - 一句一段连发、形容词堆、每段结尾都要押一句。
   - 能从场景里摘出来单独传播的格言，比如"权力从来不问死了几个人"。
   - "不是 X，而是 Y""他没有 X，只是 Y"，或者先排除几种可能再揭晓答案。Y 比 X 具体、是在纠正一个真有的误会，可以留；
     Y 比 X 大、是在拔高，要拆。
   - 段段同一个骨架：短句起头、解释一句、小转折、一句收住。
   - 用"局面复杂""事情很严重""压迫感"这类判断和抽象词代替谁在哪看见了什么、做了什么。
   - 同一个动作反复用来表示同一种情绪，第三次攥拳头就不疼了。把"他很难过"换成握拳、低头、胸口一紧，也是套。
   - 跟没人吵架："他并不是害怕，只是……"，反驳一个谁也没提过的说法。
   - 叙述者替场面标价：直接说"厉害""恰到好处"，或者全场一起倒吸凉气、齐声叹服。
   - 张力收得太快：吵完马上和好，挫折之后立刻找补一个好处，故意留的模糊被一句话讲死。
   - 章尾一段替读者总结："那一刻他终于明白……"
   - 比喻不是从这个人的经历里来的，不解释读者就不知道它指什么。
   - 对话里人物把主题说出口；或者你一句我一句一样长，谁也不压谁。

   同一类反复出现、读着出戏才列；只出现一次的不算。引一处最典型的，说明全章还有几处。
8. **腔调串了**：哪句台词不像这个人说的，哪句心声不像主角；或者几个人说话一样冷静、完整、机灵，分不出谁是谁。对照 人物/ 里"他心里怎么说话""他嘴上怎么说话"的样本。

## 不算问题

- 人物的猜测、传闻、误判，只要正文写清楚那是猜测。
- 作者在 作品.md 或 决定.md 里明确要的风格；作品.md"文风约定"里写明的写法。

拿不准的别列成提醒，放进总体印象里说。
