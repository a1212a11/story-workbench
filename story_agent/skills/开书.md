# 开书：从一句想法到能动笔

用在：作品目录几乎是空的，或作者刚说了一个想法还没有设定、人物、大纲。

## 目标

三次审批之内让作品能动笔：作品.md 写清楚、三到五个核心设定、主要人物、前三章的剧情与结尾。

## 步骤

1. **先问最少的问题。** 只问两件事：这是个什么故事（一句话），想写多长。作者答了就往下走；作者说"你看着办"就按下面的默认提议，把提议写进审批卡，让作者用批准代替回答。作者想一起想，就按 共创 的节奏（用 skill 查），一件一件来。
2. **作品.md。** 题材与基调、篇幅、作者的偏好与禁忌、文风约定（视角与人称、引号用「」还是""、
   计时用这个世界的说法而不是小时分钟秒、句长节奏一句话、幽默怎么用一句话）。作者没说偏好，就写"待作者补充"，不替作者编。
3. **核心设定，一题一文件放进 设定/。** 只写故事需要的：这个世界和现实差在哪、这种差异怎么影响普通人的一天、主角所在的行当怎么运转。每条设定写清楚"读者从哪一章开始知道"。不写百科；一条设定超过十行就多了。
4. **主要人物，一人一文件放进 人物/。** 按 人物 方法（用 skill 查）的结构建：主要人物每节都填，
   尤其"他心里怎么说话""他嘴上怎么说话"两节，那是写正文时的声音。配角只填前三节。
5. **前三章大纲写进 大纲.md。** 每章一段：本章剧情（三到五句，有一个作者做出选择的时刻）、结尾状态（此刻谁在哪、谁知道什么、什么还没解决）、状态（未写）。全书走向写一段，说到结局即可。
6. 全部经作者批准后，提议"开始写第一章"。

## 默认提议（作者说得少时）

- 篇幅：每章 1500 到 2500 字。
- 视角：第三人称限知，跟主角。
- 第一章必须有：主角在干他每天干的事、一个具体的私人牵挂、一个把他推离日常的事件。
- 每章结尾状态要能让下一章直接接上。

## 作品.md 还是占位的时候

括号里的提示还在，说明题材、基调、篇幅、偏好都没定。别急着写新章：
先按上面的做法把它们补上，作者说不清就按已有正文归纳后提议，请他批准。

## 不做

- 不一次写十章大纲，三章够了；写完三章再往后规划。
- 不替作者定他没提过的世界观大项，先问。
