# 定章：确定一章的剧情与结尾状态

用在：要写某一章之前，大纲里这章还是空的或太粗。

## 结果

大纲.md 里这一章有这几项，经作者批准：

- **本章剧情**：三到五句。写清楚谁做了什么、遇到什么、做了什么选择。至少有一个选择带代价。
- **决定 · 代价 · 钩子**：主角这章做的决定、付的代价、结尾读者想知道的那件事。
- **情绪线**：他这章心里过的是什么；每个场面的温度，一句一场。
  作者在对话里提的临时要求（"这章别太苦""让他嘴硬一点"）写进这一行，它会随大纲传给重写。
- **重场 · 带过**：这章是为哪一两个场面存在的，一般就是做决定的那场和付代价的那场；
  读者最想看的、最难写的就是它们，字要花在这里。再列出一句带过的：进场、赶路、交代谁站在哪。
- **结尾状态**：必须能写成"此刻谁在哪、谁知道什么、什么还没解决"。下一章就从这里接。
- **状态**：未写 / 已写待定 / 已定稿。

## 怎么定

1. 读 故事状态.md 和上一章结尾状态。本章的开头必须接得上。
2. 读 大纲.md 的全书走向。本章要往那个方向推进一步，说得出推进了什么。
3. 作者说过想法就整理作者的；作者没说就自己提议，理由写在对话里，不写进大纲。
   提议先过 剧情 那张单子（用 skill 查）：这章主角做了什么决定、赢了什么、对手在哪、钩子是什么。
4. 检查结尾状态：读者知道的比人物多还是少？有没有新的悬念？有就写出来。
5. 弹审批卡，作者批准后才算定了。

## 常见问题

- 剧情只有观察和移动，没有选择。改：让主角在两件都想要的事之间选一件。
- 结尾状态写成"很紧张"这种情绪。改：写成事实，谁在哪、什么没解决。
- 结尾和上一章重复。改：每章结尾至少改变一件事的状态。
- 重场写成"逃生"这种一整段过程。改：落到一个时刻，比如"他看着佟老三折回去拉二狗，自己没回头"。
- 代价没进重场。死的人、丢的东西、没做到的事，是读者会记住这一章的地方，不能只在剧情里提一句。
- 情绪线写成"很悲伤"。改：写他在躲什么、他拿什么撑着，比如"不敢想煤堆是温的；靠数人头撑着"。
