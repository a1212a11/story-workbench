# 人物：建一份写正文时用得上的人物文件

用在：开书立人物、共创里定下一个新人物、写章前发现人物文件缺"心里怎么说话"那一节。

## 为什么不是履历

身份、经历、立场是资料，写正文时用不上。正文里的人是靠三样东西活的：他此刻想要什么、
他心里怎么跟自己说话、他的身体在干什么。人物文件要给的是这三样，履历只留一句话。

## 文件结构

```
# 名字

## 一句话
（身份、处境、他在这一卷里的位置。一句。）

## 想要 · 怕 · 打架
（他想要的两件事怎么撞；他最怕失去什么。人物是靠选择刻画的，这一节决定他每章怎么选。）

## 他心里怎么说话
（五到八句内心独白样本。含吐槽、含害怕、含他不肯承认的念头。写正文时用这个声音。）

## 他嘴上怎么说话
（句子长短、对谁客气对谁不、口头禅。附三句他会说的台词。）

## 身体习惯
（紧张时手放哪、疼了怎么忍、笑起来什么样、累了先垮哪里。）

## 别人眼里的他
（两三个人各一句。同一个人在不同人眼里不一样，人物就立体了。）

## 这一卷他变成什么
（从哪到哪，哪一章转的。）

## 待定
```

主要人物每节都填。配角只填前三节，"心里怎么说话"可以只给两三句。

## 怎么写样本

- "心里怎么说话"是给写章照着写的声音，不是给读者看的段落。写他在具体处境里的一句话，
  不写"他是个乐观的人"这种概括。参考：
  - 井火旺是吉兆。行，那我这个吉兆看得头皮发麻。
  - 督办大人先问册子，不问死了几个。我得记住这个顺序。
  - 姐夫要是在这儿，会先给我倒杯热的，然后一句话不问。我现在特别想要那杯热的。
- 三种都要有：他扛不住时拿来自保的吐槽；他真正害怕的；他不肯对自己承认的念头。
- "嘴上怎么说话"要写出和别人的区别。书里所有人一个腔，就是这一节没写。
  韩敬之说话像核对报表，一句是一句；佟老三嗓门大、话糙、句尾带笑。写出这种差别。
- 样本句不能原样搬进正文。正文里用的是这个声音，不是这几句话。
- 作者纠正样本时，只改被纠正的那句，别趁机重写整节。

## 已有的旧人物文件

不自动改。写章前发现缺"心里怎么说话""嘴上怎么说话"两节，就先按这个结构补上这两节，
其余内容整理进对应的节，经作者批准再动笔。
