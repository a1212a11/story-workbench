# 写章：动笔写一章正文

用在：大纲里这章有剧情与结尾，要写或重写正文。

## 动笔前读什么

1. 作品.md：基调、篇幅、作者偏好与禁忌、文风约定。
2. 大纲.md：本章剧情、决定、代价、钩子、情绪线、结尾状态；全书走向。
3. 故事状态.md：已成立的事实、各人物知道什么、读者知道什么、未回收的线索。
4. 出场人物的文件，重点是"他心里怎么说话""他嘴上怎么说话""身体习惯"三节；本章会碰到的设定文件。
5. 上一章正文的最后三段，接口气。
6. 草稿/范文/ 里作者放的范文，有就读一篇。学它的句子密度、对话节奏和市井味，不抄情节，不抄句子。

不读完这些不动笔。两种情况先停下补材料，补完再写：

- 主角或本章主要人物的文件缺"心里怎么说话""嘴上怎么说话"两节 → 先按 人物 方法（用 skill 查）补上，经作者批准。
- 大纲里本章没有"情绪线" → 先按 定章 方法补一行，经作者批准。

## 四步

1. **初稿。** 写进 `草稿/第NN章-初稿.md`，自由文件，直接写，不弹卡。按下面的默认写。
2. **重写。** 调 `rewrite` 工具，给它初稿路径。它在一个没有对话历史的新上下文里，
   从主角脑子里把这章重写一遍，只拿到作品.md、本章大纲、人物文件、范文和初稿，
   大纲的剧情与结尾是它的硬约束。它返回全文，不写文件。
3. **捡回好句，落正文。** 把重写稿读一遍：它有时会删掉初稿里更好的句子，有时会为了有感觉而用力过猛
   （一句一段连发、金句连发），有时会越过大纲多说一件事，有时又去腔去过了头：段落变薄、句子一律短而齐、
   判断磨成了说明书，连读像提纲。以重写稿为底，把初稿里明显更好的句子捡回来，
   过火的收一收，磨平的补回来，越线的按大纲改回来。然后用 `edit` 写进 `章节/第NN章.md`，弹审批卡。
4. **审读再修。** 用 `review` 审读。有提醒先说处理意见，再改（要审批）。
   改完把 大纲.md 里本章状态改为"已写待定"，提议作者读一遍。

一轮里 rewrite 和 review 各只能调一次；作者要再来一遍就下一轮。

## 默认

- 篇幅按作品.md；没写就 1500 到 2500 字。
- 视角按作品.md；没写就第三人称限知，跟主角。读者住在他脑子里：他的心声直接写进叙述，用人物文件里那个声音，不加引号。
- 情绪不直接说，让它从身体、动作、数数、物件和心声里漏出来。人吓坏了会去数没用的东西，会盯着自己的手看。
- 世界的特别之处通过动作和物件出现，不通过讲解。一段里出现两个以上新名词就多了。
  新名词第一次出现给读者一个抓手：它是哪一类东西，或者有人当场对它有反应。
  读者知道该问什么是悬念，连这个词是什么都不知道是噪音。
- 心声贴着他写：叙述直接用他的词和他的判断，不写"他想""他感到""他意识到"。
  平时可以离他远一点，情绪最高的那一段要贴到最近。
- 心里戏要落地：挨了一下之后，他怎么消化、卡在哪个两难上、最后决定干什么。心声转一圈没落到决定上，就是空转。
- "厉害""要命""这事不小"由场面里有利害的人当场说出来，不由叙述者断言。
  写一个人之前先答：他此刻在保什么、在算什么？答不上来的人不给镜头，更别让全场一起转头。
- 状态变化写出中间几步。只给前后两头的是概述，不是场景。几样同类的东西并列，头一样写足，后面一样比一样短。
- 对话里每个人都有一个没说出口的目的。人物不把主题说出口；也别你一句我一句一样长，像打球。
- 优先动用已经有的东西：一条供暖管道、一间铺子、一个配角、一件旧物。旧细节复用得越多，故事越咬合。
- 对话短，人物说的是他此刻想要的东西，不是背景。每个人按他自己的说法说话。
- 死了人要有名字，主角要为他付一次情绪，哪怕只是一句心里话。
- 结尾落在大纲写的结尾状态上，不多写一段"下一章预告"。

## 硬规则

- 不引入大纲和设定里没有的持久设定。行业规矩、"铁律"、机构、职务、器物、地名、新人物都算。
  动笔前把本章会新出现的列给作者，作者点头再写；写完逐条核对，没进 设定/ 或 人物/ 的，提议补文件或从正文里删掉。
- 人物只能知道 故事状态.md 说他知道的事。
- 不改变前面章节已经成立的事实。
- 正文写进 章节/第NN章.md，第一行是章名（# 第N章 标题），下面是正文。
