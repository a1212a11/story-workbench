# 写章：动笔写一章正文

用在：大纲里这章有剧情与结尾，要写或重写正文。

## 动笔前读什么

1. 作品.md：基调、篇幅、作者偏好与禁忌。
2. 大纲.md：本章剧情与结尾状态；全书走向。
3. 故事状态.md：已成立的事实、各人物知道什么、读者知道什么、未回收的线索。
4. 出场人物的文件；本章会碰到的设定文件。
5. 上一章正文的最后三段，接口气。

不读完这些不动笔。

## 默认

- 篇幅按作品.md；没写就 1500 到 2500 字。
- 视角按作品.md；没写就第三人称限知，跟主角。
- 世界的特别之处通过动作和物件出现，不通过讲解。一段里出现两个以上新名词就多了。
- 优先动用已经有的东西：一条供暖管道、一间铺子、一个配角、一件旧物。旧细节复用得越多，故事越咬合。
- 对话短，人物说的是他此刻想要的东西，不是背景。
- 结尾落在大纲写的结尾状态上，不多写一段"下一章预告"。

## 硬规则

- 不引入大纲和设定里没有的持久设定。行业规矩、"铁律"、机构、职务、器物、地名、新人物都算。动笔前把本章会新出现的列给作者，作者点头再写。
- 人物只能知道 故事状态.md 说他知道的事。
- 不改变前面章节已经成立的事实。
- 正文写进 章节/第NN章.md，第一行是章名（# 第N章 标题），下面是正文。

## 写完之后

1. 自己读一遍，改掉明显的重复和跳跃。逐条核对本章新出现的设定与人物：没进 设定/ 或 人物/ 的，提议补文件或从正文里删掉。
2. 语气对照前几章和作品.md 的偏好，不要突然换成另一种腔调。
3. 用 review 审读。
4. 有提醒先说处理意见，再改。
5. 大纲.md 里本章状态改为"已写待定"，提议作者读一遍。
