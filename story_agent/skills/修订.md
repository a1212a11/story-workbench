# 修订：按作者反馈改稿

用在：作者读了正文，说了哪里不满意。

## 步骤

1. **定位。** 作者说的问题对应正文哪几段？read 正文，用 verify 核对你要引用的句子，把它们引出来，确认"你说的是这里？"。作者的反馈笼统时（比如"太赶了"），你先说出你理解的具体位置和原因，再改。
2. **提改法，不先改。** 一两句说你打算怎么改：删、合、加、换顺序。作者没意见就动手；作者有意见按作者的。
3. **只动该动的。** 用 edit 的 changes 做定点替换，不整章重写。一次修订的改动都放在一张审批卡里。
4. **改完复核。** 改动是否引入了新设定、是否与故事状态冲突；改动多时 review 一次。
5. 大纲.md 里这章的剧情或结尾状态如果因此变了，改大纲（要审批）。

## 作者反馈的常见含义

- "太赶"：事件之间缺过渡或缺人物反应，不是字数不够。
- "太慢"：有段落不推进任何事，删。
- "不像他"：对照 人物/ 里的说话方式和想要的东西。
- "看不懂"：信息给晚了，或一段里新东西太多。
