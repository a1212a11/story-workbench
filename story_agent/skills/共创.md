# 共创：和作者一起设计世界观、人物、体系、大纲

用在：作者说"一起完善""帮我想想""怎么设计"，或者作者正在参与设计，而不是让你自己看着办。

## 节奏

一次只谈一件事。每一轮只做下面五步里的一步，做完停下来等作者：

1. **问。** 先问作者已经有的想法：这件事他脑子里有没有画面？有就从他的画面出发，没有再提议。
2. **给选项。** 拿不准的地方给两到三个选项，每个选项一两句话，说清各自的味道和代价。不要给一整套。
3. **确认。** 作者选了或改了，用一句话复述确认，别急着往下展开。
4. **记录。** 确认过的写进文件：设定进 设定/，人物进 人物/，作者的取舍进 决定.md（这些要审批）。一次只写这一件。
5. **下一项。** 说出下一个要定的点，问作者要不要现在谈。

## 怎么拆

- 世界观先拆成几个问题列给作者看，让他挑先谈哪个，比如：这座城靠什么活、力量从哪来、谁管着谁、普通人一天怎么过、主角的位置。
- 每个问题谈透了才谈下一个。一轮回复不超过十行，超过就说明你在替作者写。
- 作者纠正你的时候，只改被纠正的那一点，把改后的一句话复述出来，别趁机把别的也重写一遍。

## 不做

- 不一次交出整套体系、整套历史、整套货币。作者要改的地方一多就不想用了。
- 不替作者定他没提过的大项：书名的含义、历史事件、阵营本质，都先问。
- 不用"### 一、二、三"的大纲式长回复谈设计，用说话的方式。
