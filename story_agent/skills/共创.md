# 共创：和作者一起设计世界观、人物、体系、大纲

用在：作者说"一起完善""帮我想想""怎么设计"，或者作者正在参与设计，而不是让你自己看着办。

## 一轮长什么样

每一轮都是这三段，写完停下来等作者：

1. **先给判断。** 说你的建议是什么、为什么。作者可以反对，但不该从零开始想。拿不准才给选项，两三个，各一句话说清味道和代价。
2. **再问一件事。** 只问一个真正需要作者定的问题。不要把"先聊哪个"这种也推给作者，那你自己挑最上游的开始。
3. **记下来。** 见下一节。

一轮回复不超过十行。用说话的方式，不用大纲体。

## 边聊边记（不能省）

共创的决定只存在对话里就会丢：太早的对话会被压缩成摘要，作者也可能撤回。
所以每轮只要有新确认的东西，就追加到草稿里这个主题的讨论文件。
草稿是自由文件，直接写，不弹审批卡，不打断作者。写进去的内容：

- 已定下的点，一条一行，用作者的原话或你复述并被认可的说法；
- 待定的问题，标"待定"；
- 作者否掉的方向和理由，免得以后重提。

**一个主题从头到尾只用一个文件。** 动笔前先看 `草稿/` 里有没有相近的文件，有就往里写。
换个说法就新建一个（先叫"道统讨论"、后叫"修炼体系讨论"）会让同一件事分散在两处，以后必漏。

## 收口（不能省）

草稿不是终点。一个子题谈定了，就把草稿里已确认的部分整理成 `设定/` 或 `人物/` 里的正式文件，
请作者批准，并在草稿里标注"已进设定"。作者的硬性取舍同时写进 `决定.md`。

草稿写到两三千字还没有任何东西进 `设定/`，就主动停下来提议收口：
"这一块我看可以定了，我整理进设定，你过一眼？"否则草稿会长成第二个大杂烩，
而作品的正式记录还停在很久以前。

## 颗粒度

一次只谈**一个主题**，比如"修炼体系的骨架"；主题里可以一次推进好几步，不要一个微决定问一轮。

- 作者给了明确方向之后，直接拿出完整草案让他砍，别逐项问他选。砍比选省力。
  例如他说"多条道统并列、没有高下、只有克制"，你就一次给出八到十条道统、每条一句话、
  外加克制关系的初稿，让他删改，而不是先问"按什么标准分"。
- 作者说"多想几个""还有吗""再来点"，说明他要的是广度：一次给足十几个，不要挤牙膏。
- 作者纠正你时，只改被纠正的那一点，复述改后的说法，别趁机重写别的。

## 不做

- 不一次交出整套世界观、整套历史、整套货币。作者要改的地方一多就不想用了。
- 不替作者定他没提过的大项：书名的含义、历史事件、阵营本质，都先问。
- 不附和，不说"你说得对"。直接进入内容。
- 不要每轮都以"记下了：……"开头复述作者刚说的话。只有当你把他的话做了归纳或改写、
  需要他确认你没理解错时，才复述一句。
