### 2026-09-14 引用定位修复后的真实检查

模型只需返回逐字原文，程序使用唯一精确匹配计算位置；缺失、空引用或重复出现（含重叠重复）都拒绝。旧响应中的整数 start/end 字段仍可解析，但不作为定位依据。检查问题、候选事实与阅读诊断共用此规则；领域与数据库最终的 `body[start:end] == quote` 校验保留。原失败样本经离线回放，位置正确保存为 `[0,49)` 和 `[14,32)`；不存在或重复的引用使整个检查失败、无候选事实落库。

本地回归通过后，按作者确认只对原 49 字正文发起一次真实检查，不重新生成正文、不自动重试。执行 `tests/test_provider_live.py::test_live_inspection_evidence_locations`：**1 passed in 2.69s**；应用检查约 **2.08 秒**，输入 **521 token**、输出 **356 token**，保存 **3 条候选事实、0 个问题**，每条引用区间与正文精确一致，检查 run 为 succeeded，未采用正文。这只证明该样本的接口与引用定位通过，不代表语义无遗漏或三章验收完成。密钥未写入文件。
