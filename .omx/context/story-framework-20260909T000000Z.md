- 任务：用户表示“我觉得可以考虑设计框架了”；交付可评审架构，不实现应用。
- 目标：将既有创作、采用、状态和恢复需求落实到模块、调用边界、持久化合同及实施验收。
- 证据：docs/requirements.md、docs/implementation.md、docs/three-chapter-walkthrough.md；当前只有文档，没有应用或测试。现有文档有未提交修改，必须保留。

- 约束：先本地 CLI，无需 Markdown 知识；本章最小输入仍是剧情和结尾状态；允许试写；未采用内容不得成为正式状态；不新增依赖、不建云服务、不运行付费模型。
- 方案候选沿用仓库已有 Python、SQLite、Markdown 建议；供应商、SDK、终端编辑组件、预算、支持平台尚未锁定。本轮不依赖具体第三方 API 行为，不进行外部技术选型。
