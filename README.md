# Story Workbench

AI 小说创作与故事工程系统。作者决定故事，AI 帮助讨论、组织设定，并将确定的章节剧情与结尾状态写成正文。

当前阶段：需求与方案整理，尚未实现应用。

## 文档

- [需求基线](docs/requirements.md)：产品边界、功能需求、权限规则与验收场景。
- [实施方案](docs/implementation.md)：页面流程、数据模型、AI 职责、交付顺序与待定事项。

## 核心闭环

想法讨论 → 作者确定 → 故事设计 → 本章剧情与结尾状态 → 写作草稿 → 作者采用 → 故事状态更新 → 下一章。
